# Historical material

These files were collected from an earlier repository snapshot. Several guides
target an STM32F405 running Arduino/PlatformIO or describe alternatives that are
no longer the intended architecture. They are kept for historical context and
should not be followed as setup instructions for the Raspberry Pi/PX4 system.

[vtol_project_source_of_truth.md](vtol_project_source_of_truth.md) is an older
architecture review of uploaded archives, dated 2026-10-02. Its observations and
proposals refer to that snapshot. For the current architecture, see the
[system overview](../../architecture/system_overview.md).
